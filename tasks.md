- [x] **Task 10.** Consider language-level support for empty union variants (drops parser's "≥1 field per variant" rule). If yes, revisit the lander port's `Event.Timeout { padding: u8 }` sentinel when it's next touched. Open question rather than a mandate.
  - **Design decision (locked):** unions can have variants without fields; structs must always have at least one field. Empty struct init (`S {}`) is intentionally invalid — a struct with zero fields is meaningless data. Empty union variant init (`Event.Timeout`) is a legitimate language feature — a variant is a tag; the tag alone conveys information without any accompanying payload. This split is now in `grammar.md`'s "Design decisions worth preserving" section and in auto-memory `feedback_empty_variants_vs_structs.md`.
  - Investigation: the "≥1 field per variant" rule the task referenced is **not a real rule** — the parser's `variantDefinitionLineSpec` uses `optional(contained(...))` around the braces, so `Timeout` (bare identifier in a `union:` block) already parses. The real gaps are on the use side:
    - **Instantiation.** `Event.Timeout` (no braces) doesn't parse as a union initializer today — the bare form matches getter (`source.property`) shape, so the initializer path fails silently and the parse resolves as a getter, then the next token blows up with "expected newline".
    - **Pattern matching.** `case Timeout:` in a `match` block parses as a **variable pattern** (bind a fresh `Timeout` variable) since `unionPatternSpec` requires `{ fields }` braces. There's no bare-name variant pattern syntax.
  - Decision: **defer.** Two moving parts (parser initializer syntax, parser pattern syntax) with no immediate consumer — the lander code referenced in the task no longer exists in the tree, and no example fixture uses an empty variant. A clean design would need:
    1. A dedicated bare-form union-initializer path that doesn't collide with getter (probably a lookahead: `Type.Name` where `Type` resolves to a union whose variants include `Name`).
    2. A dedicated bare-form union-pattern path that outranks variable-pattern when the name matches a known variant of the subject type (analyzer disambiguation).
    Both need analyzer knowledge (which types are unions, which variants they carry) — meaning the syntax can't be purely context-free; the parser produces an ambiguous AST node and the analyzer picks the union/variant reading when it fits.
